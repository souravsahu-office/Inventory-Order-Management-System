# Inventory & Order Management System

## Tech Stack
- FastAPI
- React (Vite)
- PostgreSQL
- SQLAlchemy
- Docker
- Docker Compose
- Render
- Vercel
- Neon PostgreSQL

## Features

### Product Management
- Create Product
- Update Product
- Delete Product
- SKU Validation

### Customer Management
- Create Customer
- Delete Customer
- Unique Email Validation

### Order Management
- Create Order
- Inventory Validation
- Automatic Stock Reduction
- Automatic Total Calculation

### Dashboard
- Total Products
- Total Customers
- Total Orders
- Low Stock Products
